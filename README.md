A one-line warning label for the human species, entered in the
[Warning Label for Humans: One Line, Big Laugh](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85)
bounty on [make.fun](https://make.fun).

## The entry

> WARNING: This human has never read a warning label all the way to the end, and is not, even now, going to finish this one.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override the directory with
`MAKEFUN_OUTPUT_DIR`), then reads it back and checks it against the
competition gate: UTF-8, 1–160 characters, single line, not only
whitespace. Python standard library only; no network.
